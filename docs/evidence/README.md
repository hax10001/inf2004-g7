## How to reproduce

```bash
bash tools/run_host_tests.sh                      # ends with HOST PASS
cd app_program/dashboard && npm test              # 110/110
G7_CONSOLE=usb_cdc G7_LIVE_CONTROL=1 PICO_SDK_PATH="$HOME/pico/pico-sdk-2.2.0" ./build_uf2.sh
```

The build needs Pico SDK 2.2.0 and your own `config/wifi_credentials.h` and `config/wifi_secrets.h`. Start from the `*.example.h` files; the real ones are not in the repository.
