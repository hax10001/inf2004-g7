How to connect your Pico W

1. For read-only monitoring run npm run lan. For mapping and physical Start/Stop use bash run_live_dashboard.sh from the project root (bench only).

2. In another terminal run npm run setup:wifi. Enter the 2.4 GHz WiFi SSID and password (input is local to your Mac).

3. This project includes CYW43-owner MQTT code targeting g7/b1/robot/telemetry. Build and flash the updated UF2; this text is setup guidance, not a connection error.

4. When packets arrive, the status changes to RECEIVING LIVE PACKETS. Stop npm run demo when testing the real car.

A firewall, guest WiFi/client isolation, changed Mac DHCP IP or missing Pico MQTT hook can prevent connection. Configuration alone cannot activate unfinished Pico firmware networking.
